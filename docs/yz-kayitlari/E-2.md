## 1. İstem (Prompt)
> ASP.NET Core 8 Web API projesinde Entity Framework Core kullanarak hem Supabase PostgreSQL (`Npgsql`) hem de yerel sıfır-kurulum `SQLite` fallback destekleyen veri katmanını kur. `PrescriptiveDecisionEngine` içinde iş gücü açığı oluştuğunda yalnızca `IsMobilityAccepted == true` ve `Status == "Active"` olan, kadro fazlası bulunan donör tesis çalışanlarını en düşük `MobilityAllowanceRate` ve en yüksek `SkillScore` sırasıyla LINQ ile seçen karar motorunu ve `System.Threading.Channels` tabanlı HTTP 202 asenkron telemetri kuyruğunu geliştir.

## 2. YZ Yanıt Özeti
- `ApplicationDbContext` üzerinde 7 domain varlığı ve tüm Foreign Key (`Cascade`, `Restrict`, `SetNull`) ilişkileri tanımlandı.
- `Program.cs` içine bağlantı dizesi kontrolüne göre PostgreSQL / SQLite otomatik seçimi eklendi.
- `IngestionChannel` (`ChannelWriter<TelemetryDto>`) ve `BackgroundQueueService` (`BackgroundService`) ile scoped `ApplicationDbContext` kullanarak bloklamayan telemetri işleme hattı kuruldu.
- `PrescriptiveDecisionEngine` içine sözleşme kuralını zorunlu kılan LINQ sorgusu ve 1-tıkla onay / geri döndürme iş akışı yazıldı.
